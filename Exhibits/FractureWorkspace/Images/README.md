# Fracture Studio evidence

- `VerifiedCubeSolverComparison.png` is a validation capture of six native C++ solver results on the same cube: runtime Boussinesq, Engineering FEM, Griffith, Wavefront, Voronoi, and Dendritic. The displayed shard silhouettes are projected from each solver's generated fragment geometry by the editor UI; this is not a GPU or ReSTIR render.
- `VerifiedOverview.png`, `VerifiedPhysics.png`, `VerifiedBonds.png`, and `VerifiedSdf.png` are workspace validation/UI captures. They are not GPU-rendered evidence.
