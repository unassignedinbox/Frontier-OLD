# Studio Controls (Remastered kit, batch 1)

Headless validation and CPU-raster evidence for the shared Remastered Studio
control kit ported from `StudioControls.js` (Particle/Fracture canonical set
plus ForceField extras).

## Controls

- `SectionCard` — collapsible `.property-group` card (22 px radius, gradient,
  warm glyph, 17 px title, badge, wrapped hint).
- `SegmentedRow` — `.segmented-track` single-select pill track.
- `VectorRow` — `.vector-cell` X/Y/Z pills with coloured axis tags.
- `TextRow` — `.studio-input` single-line pill field.
- `SliderPill` — Fluid `SliderPill`: 92 px value pill (typed + scrubbed figure,
  unit cell) beside the 26 px pill track.
- `SwitchPill` — 44x25 high-contrast `.switch` toggle.
- `Toast` — transient `.toast` pill.
- Theme — `ControlTheme::ResolveRemastered()` carries the charcoal tokens.
- Glyphs — 118 `Studio*`/`StudioField*` outlines generated by
  `Automation/GenerateStudioGlyphs.py` (`<ellipse>` converted to cubic paths).

## Reproduce

```sh
cmake -S . -B build -DFRONTIER_HOST_VERIFICATION=ON
cmake --build build --target StudioControlsValidation
./build/StudioControlsValidation /tmp/StudioControlsValidation.ppm
ctest --test-dir build -R StudioControlsValidation
```

The PPM capture shows the open card (segment/track/switch/text/vector rows),
the closed card, the 118-glyph grid, and the toast. Text/vector editing paths
render only; pointer checks cover card toggle, segment select, track drag,
figure scrub, and switch flip.
